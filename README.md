# **Messenger** 🚀  
**"Полнофункциональный клон мессенджера с возможностью отправки сообщений, фото, локации и регистрации пользователей"**

---

## **О проекте**  
Этот проект представляет собой клон мессенджера на подобии WhatsApp или Viber. Приложение построено на архитектуре **MVC (Model-View-Controller)**, что обеспечивает четкое разделение логики, интерфейса и данных.  

Основные функции:  
- Регистрация и аутентификация пользователей через **Firebase Authentication**.  
- Отправка текстовых сообщений в реальном времени.  
- Возможность обмена медиафайлами (фото).  
- Отправка геолокации.  
- Хранение данных в **Firebase Firestore** и **Firebase Storage**.

---

## **Функциональные возможности** ✨  
1. **Регистрация и вход:**  
   - Пользователи могут зарегистрироваться через email и пароль.  
   - Восстановление пароля через Firebase.  

2. **Чаты:**  
   - Отправка текстовых сообщений в реальном времени.  
   - Поддержка групповых чатов (опционально).  

3. **Медиа:**  
   - Отправка фотографий с предварительным просмотром.  
   - Хранение изображений в Firebase Storage.  

4. **Геолокация:**  
   - Пользователи могут делиться своей текущей локацией.  

5. **Бэкенд:**  
   - Firebase Authentication для управления пользователями.  
   - Firebase Firestore для хранения сообщений и метаданных.  
   - Firebase Storage для загрузки и хранения медиафайлов.  

---

## **Технологии и подходы** 💻  
- **Язык программирования**: Swift (iOS)  
- **Архитектура**: MVC (Model-View-Controller)  
- **Бэкенд**: Firebase (Authentication, Firestore, Storage)  
- **Дополнительно**:  
  - Реализация работы с геолокацией через CoreLocation.  
  - Использование UIKit для создания интерфейса.
